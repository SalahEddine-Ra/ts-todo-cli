# 📝 TypeScript Todo CLI

A simple **command-line todo manager** built with TypeScript and Node.js.  
It supports adding, listing, toggling, editing, and removing todos — all stored in a JSON file.

---

## 🚀 Features
- Add new todos
- List all todos
- Toggle completed state
- Edit todo text
- Remove todos
- Colorful CLI output

---

## 📦 Installation
Clone the repo:
```bash
git clone https://github.com/YOUR-USERNAME/ts-todo-cli.git
cd ts-todo-cli
npm install
